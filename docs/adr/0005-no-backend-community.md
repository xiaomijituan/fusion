# 项目三无后端社区：砍排行榜与账号，文件即分享物

项目三（中文可运行手册 / 社区内容）设想过"排行榜：谁的任务完成率最高、谁 blocked 最少"与账号式配置分享。这需要账号 + 后端 + 持久化，与初版需求清单第 8 条"无账号、无数据库、状态在浏览器里"直接冲突，也与 ADR-0002"v1 无对错概念"矛盾——完成率排行预设了标准答案。决定：**砍掉排行榜与一切账号/后端形态的社区功能。分享物就是文件本身**：剧本（Scenario 文件）与战绩（导出的 JSONL 事件流）都可粘贴/传阅/提交 PR，社区性由 git 与内容平台承载，不由服务器承载。

## Consequences

- 项目三（手册仓库）嵌入模拟器用 **iframe + postMessage**：章节页持有剧本 JSON，注入 iframe 内的应用——不触发 URL fetch（与 Q6 导入边界一致），数据仍是静态的。
- "一章 = 一段正文 + 一个可玩 Scenario"成为项目三的内容单元约定。
- 若日后真要排行榜，前提是先接受"对错"语义（推翻 ADR-0002）+ 引入后端，属新产品决策，不在 v1 延长线上。
