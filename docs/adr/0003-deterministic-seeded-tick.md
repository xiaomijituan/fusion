# 确定性推进：带种子 PRNG 驱动环境 tick

教学模拟器的核心承诺是可重放——学员导出的一局要能被别人复现、社区剧本能写"标准路径"、QA 能断言。为此环境推进（进度增长、随机 blocked、done→idle、idle 自接任务）全部改走一个带种子的伪随机数发生器（mulberry32 级），种子存进 Run 并写入事件流头。

保证：**同一剧本 + 同一种子 + 同一决策序列 ⇒ 同一事件流**。人的 Decision 是唯一非确定源，PRNG 只固定"环境怎么动"。

## Consequences

- 现状 `store.ts` 的 `tick()` 用 `Math.random()`，需替换为从 Run 种子派生的 PRNG 流。
- 事件流必须记录种子，否则重放无从复现（与 ADR-0002 事件流为唯一产物一致）。
- 真实感的"随机"不受损——种子伪随机对玩家不可区分，但可复现。
